# Rig Book

Un'app web per segnare il tuo gear musicale e da studio: chitarre, bassi, ampli, pedali, schede audio, monitor, microfoni, computer.

Per chitarre e bassi puoi segnare scalatura, corde, accordatura e la data dell'ultimo cambio corde.

- Funziona anche offline e si installa sul telefono ("Aggiungi alla schermata Home").
- I dati restano solo sul tuo dispositivo: nessun account, nessun server.
- Con "Esporta backup" salvi un file `.json`, con "Importa" lo ricarichi su un altro dispositivo.

Sito statico: `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`. Nessuna build.
